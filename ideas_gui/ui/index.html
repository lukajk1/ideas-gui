        Quick capture
        
                
        
                    
        
                        
                        
                    
        
                    
        A shortcut that works from anywhere in Windows and opens a small box to jot an idea down. Click the box, then press the keys.

        / or Ctrl+F
        Search
        
                
        N
        New idea
        
                
        R
        Random idea from the current list
        
                
        S
        Shuffle the list
        
                
        J K or ↓ ↑
        Move through the list
        
                
        Enter
        Edit the selected idea
        
                
        Esc
        Back to the list
        
                
        1 – 5
        Set status (Ctrl+1–5 while typing)

        Open in text editor
        
                
        Del
        Delete
        
                
        Ctrl+S
        Save now (it also saves as you type)
        
                
        V
        Switch between Ideas and Stats
